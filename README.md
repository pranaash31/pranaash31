## Artificial Intelligence & Machine Learning Engineer

My work in AI and Machine Learning focuses on applying intelligent techniques to practical engineering problems.

At **Appin Technologies**, I built an automated job intelligence pipeline aggregating opportunities from more than 10 recruitment platforms. The system reduced manual job discovery effort by 70%. I also developed an NLP engine using **Sentence Transformers** to extract technical skills and generate personalized learning recommendations.

At **Gradtwin**, I worked as a Machine Learning Engineer Intern on **PromptShield**, an NLP-based security layer for an enterprise AI assistant. I developed a classification pipeline using **Sentence Transformers and Scikit-learn** to detect prompt injection and jailbreak attempts before they reached the LLM. I also built a **Flask inference API** with confidence scoring for secure prompt validation, with inference latency under 100 ms.

My technical interests include Generative AI, Retrieval-Augmented Generation, intelligent agents, semantic similarity, and AI security.
